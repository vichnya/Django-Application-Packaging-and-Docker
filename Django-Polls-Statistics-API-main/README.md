# Django Polls Statistics API

Учебное веб-приложение на Django, расширяющее приложение с опросами возможностями статистического анализа результатов голосования.

## Цель

На практике изучить создание REST API для получения статистики голосований, работу с фильтрацией данных и визуализацию результатов с помощью графиков.

## Что реализовано

* отдельная страница статистики для опросов;
* REST API для получения статистики голосований;
* подсчёт общего количества голосов;
* подсчёт количества голосов за каждый вариант ответа;
* расчёт процентного соотношения голосов;
* определение наиболее и наименее популярного варианта ответа;
* фильтрация данных по дате;
* визуализация результатов голосования;
* формирование графика в формате SVG;
* интеграция статистики с существующим приложением опросов.

## Статистика голосований

API позволяет получить информацию о результатах голосования, включая:

* общее количество голосов;
* количество голосов за каждый вариант;
* процент голосов каждого варианта;
* наиболее популярный вариант;
* наименее популярный вариант.

Также предусмотрена фильтрация статистики по диапазону дат.
